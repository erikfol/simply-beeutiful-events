# Reference sites for SBE development

Inspiration and competitive research for the Event Manager. Check before building new features — borrow what works.

## https://www.timelinegenius.com/ — wedding timeline generator (planner software)
- Smart timeline creation: answer a few questions → customized initial timeline. (We could do this: ceremony time + venue → prefilled run sheet.)
- Timeline templates (preset + custom). (Maps to our per-event `.timeline.json` — could add a shared template library.)
- Bulk time-shifting: shift many items at once. (Good feature request for our editable spine.)
- Branding preferences on timelines. (We have SBE logo/colors — could extend to printable view.)
- Tailored timelines per audience (clients vs vendors see only relevant items). (Feature idea: filter run sheet by role.)
- Timeline PDFs for email/print. (Matches improvement plan item: PDF export.)
- Collaboration, contacts rolodex, file management, text reminders, time tracking. (Bigger scope — backend territory.)
